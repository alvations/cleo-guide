# Design decisions — beta (UI/UX lane)

Recorded instead of asked (charter: never stop to ask). Each: decision · why · rejected alternatives. PM decisions
live in `docs/BETA-DECISIONS.md`; these are the design-lane calls under them.

| # | Decision | Why | Rejected |
|---|---|---|---|
| UX-01 | **Direction "Constellation"**: every city drawn as the star-map of its verified pins; Salon's IA kept, its visual layer replaced. | The research's verdict on Salon: right IA, no wanderlust, no visual anchor. Constellations are wanderlust that is *true* — our trust promise made visible — and no competitor can copy them without our data. | Photo-led cards (no licensed photos; fabrication risk); Salon ivory-only (judged "a column of text"); neon night bar (owner: "night-bar, not wanderlust"). |
| UX-02 | **Bodoni Moda (display) + Figtree (UI)**, native script via system Mincho → Noto Serif JP subset. | "High fashion" = a Didone; "fun" = a friendly geometric sans; two families (M1-15). Bodoni Moda has an optical-size axis (legible at 21 px) and renders macrons. | Fraunces (the beta the owner disliked); Newsreader alone (bookish, not fashion); Playfair (over-used). |
| UX-03 | **One shared frame + one accent per city (8 skins)**, area colours only as tints. | Luxury = restraint (Aman, Rosewood); fun = local character (The Hoxton). Accent spent on actions & active state only. | Brass on everything (current beta); a single global accent (Tokyo = Chicago). |
| UX-04 | **Gilt is reserved for distinctions**; the primary action is ink. | Keeps the ladder legible; ink buttons read "fashion house", not OTA. | Accent-coloured CTAs everywhere (dilutes the city accent). |
| UX-05 | **Tier ladder glyphs**: filled compass star in ring / outlined star in ring + dot / open diamond, always with the text label. | Original marks derived from our compass-star brand mark; no resemblance to Michelin's flower or Bib, Airbnb's laurel, Tripadvisor's owl. | Stars (rating connotation), numbers (looks like a score), text-only (fails P18). |
| UX-06 | **Cover cards on mobile** (136 px plate on top) instead of Salon's text rows; compact `.row` density kept for sheets/day plan/tray option. | Visual anchor per place (M1-11); Airbnb-grade scanning; still ≥ 2 cards per screen after the first. | Horizontal 104 px thumbnail rows (chips wrapped to 3 lines at 390 px; read as a list app). |
| UX-07 | **Pin number sits on the plate corner**, not in the card body. | M1-04 needs card = pin numbers; M1-11 bans "machinery above the name". The plate is art, so the number reads as a map label (Eater 38), not UI. | Number before the name (old engine "001"); no number (breaks map↔list matching). |
| UX-08 | **Native script set vertically** (writing-mode: vertical-rl), ≤ 7 glyphs, no wrap; Latin names get a Bodoni italic initial in the area colour. | Tategaki is the most "local" typographic gesture available and true data; initials keep non-CJK cities consistent. | Horizontal CJK (weaker); repeating the English name (redundant). |
| UX-09 | **Map art, not a blank box, whenever tiles are absent**: blurred area washes + pins + numbered markers, credited "Map art from our verified pins · live map © OpenStreetMap contributors · Esri". Rendered at each breakpoint's real aspect (`mapart_pair`) so pins never scale up. | M1-06; the sandbox and offline users never see an empty map. | Salon convex hulls (read as a diagram, hulls overlapped); a grey "tiles failed" panel. |
| UX-10 | **Map toggle lives in the sticky toolbar on mobile**, not a floating pill. | M1-05: the toggle may never cover a card title; research flagged Salon's floating pill. | Floating "Map" FAB (Airbnb pattern) — tried in iteration 1, covered titles. |
| UX-11 | **Mobile chrome trimmed to hit ≤ 14 on-screen controls**: top-bar search hidden on city pages (toolbar search replaces it), crumbs collapse to the parent, order note moves to the tray / method page on mobile. | M1-01 budget; measured 14 with the first card at 0.73–0.79 screens. | Dropping the segmented tabs or the rail (they are the front door). |
| UX-12 | **Source tiles in the collection rail** ("Everything recommended by Time Out · 185"). | Attribution as navigation (P20) on the first screen, not buried in a filter. | Source filter chips (live engine's admin vocabulary). |
| UX-13 | **"Look for" vs "Your guide's note"** decided per record (`k` prose test: ≥ 8 words and a full stop). | Research §7.2(4): a butler that speaks in tags feels broken. | Always "note" (Salon); always tags (loses Cleveland's real tips). |
| UX-14 | **Picker interests = backlog M2-05 list**; mood "Nightlife & yokochō" only because Tokyo has a `NIGHT` collection. | M2-11 forbids "after dark" without data; every option maps to collection/cuisine ids. | Owner's three words only (narrower than the PM's five); "After dark" (no hours data). |
| UX-15 | **Closed-since-saved** is shown in the saved list, flagged, never auto-removed. | Rule 4c spirit — closed places stay, flagged — applied to the user's own data. | Silently dropping it (lies by omission). |
| UX-16 | **Dark mode = night edition by token**, OS-driven with a `data-theme` override; not marketed as a feature. | Research: dark mode is not table stakes, but tokens make it free; AA verified. | No dark mode (current beta has one; regression). |
| UX-17 | **No photographs in Wave 0 mockups at all**, not even placeholders. | IMAGERY.md: Commons photos wait for the LP-02 registry + gate; a grey "photo" box imitates imagery. | Hotlinked Commons thumbnails (network blocked here, licence unverifiable from this sandbox, and hotlinking is discouraged). |
| UX-18 | **Hero number counts only dataset-built maps + Cleveland** ("8,067 places across 32 city maps"). | Exactly true and computed; Singapore/Vietnam engine pages aren't parsed by the mockup tool, so they are left out of the claim rather than estimated. | The registry's coordinate count (includes entries not on a live page). |
| UX-19 | **Mockups are generated, not hand-written** (`tools/make-mockups.py`), and assert every place renders. | Same discipline as the charter's "no hand-edited beta pages"; no invented place can slip in. | Static hand-coded HTML with a few cards. |
| UX-20 | **Components ship as `beta/assets/constellation.css`**, alongside the platform lane's baseline `cleo.css`, instead of overwriting it. | The platform generator's pages depend on `cleo.css`'s markup contract (RFC §5); replacing it now would unstyle live beta pages. FE lanes adopt Constellation classes page by page; once no generated page uses the baseline selectors, `cleo.css` is retired (or becomes `@import "constellation.css"`). | Overwriting `cleo.css` in Wave 0 (breaks the generator's output until FE rebuilds every template). |
