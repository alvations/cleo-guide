# HCMC East wave — Thảo Điền / An Phú / District 2 (Thủ Đức City) + District 7 (Phú Mỹ Hưng)

Discovery wave for the eastern / modern expat-upscale belt. Files (namespaced, HCMC sources kept
separate from Central/Outer): `FOOD_HCMC_EAST.json`, `SOURCES_HCMC_EAST.json`,
`CREATORS_HCMC_EAST.json`.

## Result: 12 NEW places (all pass the sourced-guide bar)

All deduped against `_hcmc_existing.txt` (109 names). None re-added. In particular the eastern-belt
places already present were **excluded**: TRE Dining, Laang, The Vintage Emporium, L'Usine (Thảo Điền),
Every Half, Okkio, Bosgaurus.

**Thảo Điền / An Phú / District 2 (9):**

- **Lửa Wine Bar** — T1 — Wine Bar. MICHELIN Guide Sommelier Award 2023 (Yu Yamamoto, first in Vietnam) + The Dot.
- **XLIII Coffee (Thảo Điền)** — T1 — specialty coffee roaster. Sprudge Build-Outs (dedicated) + The Dot. 19 Đường Số 2. (Formerly 43 Factory Coffee Roaster.)
- **La Villa French Restaurant** — T2 — French. MICHELIN Selected 2023 & 2024 (lone institutional). Ngô Quang Huy.
- **NOMU** — T2 — Japanese izakaya fusion. Vietcetera (dedicated) + Saigoneer (dedicated).
- **Mad House** — T2 — European / Scandinavian garden. Rusty Compass + Oi Vietnam + The Dot. 6/1/2 Nguyễn Ư Dĩ.
- **Mekong Merchant** — T2 — Mediterranean-Asian all-day cafe/brunch (since 2004, sibling of The Deck). Saigoneer + Rusty Compass.
- **BAKES (Thảo Điền)** — T3 — French patisserie / dessert. Two dedicated Vietcetera features.

**District 7 / Phú Mỹ Hưng (3):**
- **Mi Lanh Yoo Chun** — T1 — Korean cold noodles (naengmyeon). Saigoneer Hẻm Gems + Saigoneer Dishcovery (naengmyeon). Nguyễn Văn Linh, Tân Phong Ward.
- **Tía Tô** — T2 — Korean home cooking / banchan. Saigoneer Hẻm Gems + Saigoneer Phú Mỹ Hưng feature.
- **XÀO** — T2 — Thai noodles. Saigoneer Hẻm Gems + Saigoneer Phú Mỹ Hưng feature.

Each area has ≥1 tier-1. Cuisine tags name the kitchen's tradition (French, Japanese, Korean, Thai,
European/Scandinavian, Modern-Vietnamese), not a single dish.

### Sourcing note on the D7 gems
The three D7 hidden gems are carried by **Saigoneer** (two distinct Saigoneer editorial pieces each — a
dedicated Hẻm Gems long-form feature plus a second Saigoneer article). This is single-outlet coverage;
it clears the "traceable to a real recommender" promise via dedicated long-form features rather than a
listicle line. If the project wants strict cross-outlet ≥2 for these, a short pass can add a second
credible outlet (Vietcetera / The Word / Rusty Compass) or drop to Saigoneer-only-flagged.

### OPEN/CLOSED
All 12 verified **open** as of 2025/2026 research (The Deck actively cited in recent world's-best-bars
coverage; Mekong Merchant/Pendolasco-era D2 mainstays confirmed operating; XLIII, An's, Lửa, BAKES,
Østerberg all current). `closed:false` on every record. No permanently-closed places found in-scope
this wave.
